# Jackpot Lottery 🎰

## Overview
A decentralized lottery system built on blockchain technology, offering transparent and fair gambling experiences.

## Features
- 🎲 Secure random number generation
- 💰 Automated prize distribution
- 🔒 Smart contract based lottery system
- 🌐 Support for multiple networks (Mainnet/Testnet)
- 🎫 Fair ticket purchasing system

## Installation
```bash
npm install
```

## Configuration
Create network configuration files in the settings folder:
- `Mainnet.toml`
- `Testnet.toml`

## Usage
```bash
# Start development server
npm run dev

# Run tests
npm test

# Deploy to network
npm run deploy
```
